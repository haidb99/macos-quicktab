# Roadmap

## Current

- Individual-window Option-Tab switching.
- MRU ordering, cancellation, reverse cycling, and menu bar settings.
- Optional ScreenCaptureKit previews.
- SPM build, DMG packaging, and GitHub CI/release automation.

## Planned

- Universal arm64 + x86_64 release verification.
- Higher-quality preview matching and more display/Space testing.
- Notarized public releases when signing infrastructure is available.
- Optional update delivery, evaluated separately from the core switcher.
- Shortcut customization after fixed Option-Tab behavior is stable.
