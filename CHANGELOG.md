# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Open-source repository documentation and GitHub workflows.
- Configurable Option, Control, and Command shortcuts with live Settings updates.
- Event-tap diagnostics for modifier mapping and permission troubleshooting.
- Bundled QuickTab app icon and drag-and-drop DMG packaging.
- Stable local signing guidance for development builds.
- Contributor, architecture, release, permissions, and troubleshooting documentation.

## [1.0.0] - 2026-10-10

### Added

- Menu bar application for macOS 14+.
- Option-Tab switching between individual windows.
- Accessibility-backed window discovery and activation.
- MRU ordering, reverse cycling, and cancellation.
- Optional ScreenCaptureKit thumbnails and bounded caching.
- SwiftUI/AppKit settings and DMG packaging.
